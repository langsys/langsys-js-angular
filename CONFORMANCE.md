**What surfaced while writing this:**

- **SRV-2 fails in a way a visitor would see.** Two concurrent Angular SSR renders through this binding's own documented hand-off (`initialTranslations`), `it-it` and `de-de`: the Italian request was served German, 2 of 2 runs in fresh processes, while each locale rendered alone was correct. The README recommended exactly that hand-off with no warning; it now states the limitation.
- **HINT-4's persistent-layout non-capture is real here, and it depends on the shape.** Across a real router navigation, with the shell persisting outside `<router-outlet>`: the pipe in a default-CD shell, a `t()` read in a shell template, and the pipe in an OnPush shell that *contains* the outlet (which `RouterOutlet` marks for check) all re-enter for the new URL; an OnPush header *beside* the outlet, a `computed` translation, and an `lsTranslate` block do not. The spec lists Angular for this "by inspection"; it is now measured, and pinned.
- **A router measurement has two traps that both read as "does not re-enter".** TestBed substitutes `MockPlatformLocation`, under which `location.href` never moves; and a navigation started outside the Angular zone never re-renders. This lane's first run hit the second and failed its own positive control on every shape — which is the only reason it was not recorded as six non-captures.
- **MARK-1 holds on the client route and not on the SSR route.** The core stamps `data-ls-contentblock` when the directive mounts in a browser; under `@angular/platform-server` the directive never constructs the core class, so the served block carries no identity.
- **SSR-3's precondition was missing from this binding's own surfaces**, although `LangsysConfig` exposes `ssrTokenStrategy: 'server'`. It is now a callout in the README and in the option's JSDoc, pinned by an artifact test.
- **The core rewrote its own record against the same target while this lane was re-rowing** (`a18e4a3`), moving dozens of its statuses. Every core citation here is read from the core's file at write time rather than carried, so each delegated row names the status the core holds now.
- **The dependency range could not match the core it was built against** (`^0.4.1` against `0.6.5`), and the lockfile resolved registry `0.4.1`.
- **Two of this lane's own verifiers were wrong before they were right.** The SSR-3 artifact test was red against a correct README — prettier had wrapped the callout, and the pattern could not cross the line — and an earlier GATE-5/6 probe had a firing control that could not fire. Each probe now asserts its control.

## Scope

A **binding**: it inherits the browser core's profile and adds nothing of its own, so most rules are the core's. Rows take one of these shapes:

- **`implemented` · `n/a (pure)`** — behaviour this binding owns, proven in-process (jsdom, no server) or by artifact inspection with a positive control, and shown by mutation to fail when the behaviour is removed.
- **`delegated` · `-`** — the core owns it. The evidence names the core's row, and an absence probe from `src/lib/conformance-probes.spec.ts` proving this binding does not participate, with the probe's firing control over the resolved core artifact. Probe counts are over code lines only: comment lines are dropped first, because this binding's prose describes the behaviour it delegates far more often than its code performs it.
- **`not implemented` · `-`** — the rule binds this binding and the behaviour is absent, measured.
- **`n/a (…)`** — with the reason, and what would change it, in the row.

## Gaps, ranked by cost

1. **SRV-2** — concurrent server renders serve each other's locale. Visitor-visible correctness: an Italian page served in German, intermittently, under traffic.
2. **SRV-1 and MARK-1** — served bytes: `lsTranslate`/`lsPhrase` content in the base language with no identity, and pipe output correct only without concurrency. Crawlers index the base language; a served block cannot be traced to its id.
3. **HINT-4** — a persistent layout whose translations live in an OnPush component beside the outlet, in a `computed`, or in an `lsTranslate` block reports nothing for the routes it is shown on. Discovery absent, silent, until the navigation entry point lands.
4. **SRV-4** — no synchronous seed before hydration and no server-to-client catalog hand-off.
5. **SRV-3** — no after-flush collection of server-render misses.
6. **SRV-5** — no server-side child capture; ownership is an open operator decision.
