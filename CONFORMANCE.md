**What surfaced while writing this:**

- **Concurrent server renders serve one visitor another visitor's language** (SRV-2): the catalog the SSR hand-off seeds is the core's process-wide module global.
- **Persistent layouts are reported for the page they are shown on only with `provideLangsysNavigation()`.** Without it, an OnPush header beside the outlet, a `computed` translation and an `lsTranslate` block in the layout never re-enter the SDK when only the route changes.
- **The core's module-level state is shared by everything in one module graph.** A test that starts `init()` outside the Angular zone leaves the catalog's arrival unrendered until the next tick — a navigation — and a second scenario in the same file inherits the first's catalog. The contract tests start quiescent and run one scenario per file.

## Scope

A **binding**: it inherits the browser core's profile, so most rules are the core's. Rows take these shapes:

- **`implemented` · `contract`** — behaviour this binding owns whose evidence is the contract double's accepted state or served catalog (HINT-13, GATE-10, SNAP-2).
- **`implemented` · `n/a (pure)`** — behaviour this binding owns, proven in-process or by artifact inspection with a positive control, and shown by mutation to fail when removed.
- **`delegated` · `-`** — the core owns it. The evidence names the core's row and an absence probe from `conformance-probes.spec.ts` proving this binding does not take part, with the probe's firing control over the resolved core artifact. Counts are over code lines only.
- **`not implemented` · `-`** — the rule binds this binding and the behaviour is absent, measured where it can be.
- **`n/a (…)`** — with the reason, and what would change it.

## Gaps, ranked by cost

1. **SRV-2** — concurrent server renders serve each other's locale: an Italian page served in German, intermittently, under traffic.
2. **SRV-1 and MARK-1** — served bytes: `lsTranslate`/`lsPhrase` content in the base language with no identity, and pipe output correct only without concurrency. Crawlers index the base language, and a served block cannot be traced to its id.
3. **SRV-4** — no synchronous seed before hydration and no server-to-client catalog hand-off.
4. **SRV-6** — the request locale is not taken from the URL, cookie or `Accept-Language` under SSR.
5. **SRV-3 and SRV-5** — no after-flush collection and no server-side child capture; ownership of capture is an open operator decision.
